# web-lab2 — ToDo-лист

Веб-приложение «Список задач» на чистом JavaScript (DOM API) без фреймворков.

**Демо:** https://bahadirahmedov.github.io/web-lab2/

## Возможности

- добавление задачи с названием и сроком выполнения;
- удаление задачи;
- редактирование названия и даты (Escape — отмена);
- отметка о выполнении с изменением оформления, подсветка просроченных задач;
- сортировка по дате (сначала ближайшие / сначала поздние / свой порядок);
- фильтрация по статусу (все / невыполненные / выполненные);
- поиск по названию;
- сохранение в `localStorage` и восстановление при загрузке;
- изменение порядка перетаскиванием (HTML Drag and Drop API, на сенсорных экранах — за «ручку» ⠿);
- адаптивная вёрстка (flex/grid, медиазапросы).

## Структура

```
index.html          — только каркас и подключение скрипта
css/style.css       — стили и адаптивность
js/main.js          — точка входа, состояние и обработчики событий
js/dom.js           — хелпер создания элементов, настройка <head>
js/layout.js        — построение структуры страницы (header, main, section, footer)
js/render.js        — отрисовка списка задач
js/store.js         — работа с задачами и localStorage
js/filters.js       — фильтрация, поиск и сортировка
js/dragAndDrop.js   — перетаскивание задач
```

## Запуск локально

Скрипты подключаются как ES-модули, поэтому страницу нужно открывать через локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```
